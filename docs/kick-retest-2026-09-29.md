두 기록 모두 좌우 킥 각 1회, 방향 일치, Twist/Neutral 오검출 0이다. 성공 사례만 제공되었으므로 중단된 두 시도의 직접 원인은 확인할 수 없다. 위 프레임 집계는 전체 WAIT_RETURN 구간이며 추가 대기 구간에 한정한 수치가 아니다. 무릎 사용 불가는 한쪽 또는 양쪽을 의미한다.

## 확인된 원인과 수정

- 기존 테스트는 Neutral 2초 후 fresh ARMED가 관측될 때까지 무기한 정지했다. 마지막 Neutral도 이 조건으로 완료가 막혔다.
- Reset Test가 테스트 기록만 지우고 인식기의 candidate/WAIT_RETURN을 남겼다. 시작 조건도 현재 pose/양쪽 무릎/ARMED를 요구했다.
- 고정 22초 타임라인으로 변경했다. 입력 누락, WAIT_RETURN, 늦은 clock tick에도 벽시계 기준으로 진행하고 완료한다.
- 카메라 실행과 Neutral 보정 완료는 필요하다. 현재 pose와 ARMED는 시작을 막지 않는다. 시작/초기화 시 보정값을 유지하고 후보·복귀 latch·이벤트·카운트·속도 이력을 초기화한다.
- 테스트 도중 detector를 강제로 re-arm하지 않는다. 기존 복귀 기준(양쪽 변위 < 0.15, 180ms)을 유지하므로 인식 실패는 miss로 드러난다. 자세 인식 정확도가 해결되었다는 의미는 아니다.

## 다음 실사용 확인

Neutral 보정 1회 후 테스트 → JSON 저장 → Reset Test → 테스트를 연속 4회 반복한다. 모든 시도가 22초로 끝나는지, 실패한 시도도 JSON 다운로드가 가능한지 확인한다. 그 기록으로 WAIT_RETURN 지속, visibility 부족, 실제 변위·속도 부족을 구분한다. 현재 카메라를 이용한 사람의 동작 재검증은 수행하지 않았다.
